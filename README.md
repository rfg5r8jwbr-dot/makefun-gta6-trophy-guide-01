An offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: every official name, description and grade, a cited guide for each trophy in our own words, a three-stage roadmap to the platinum with the one possibly missable trophy flagged, and a checklist that saves in the browser with export and import.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the hand-in bundle without serving:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
